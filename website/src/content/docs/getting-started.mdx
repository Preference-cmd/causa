## Before you start

You need Rust **1.96** or later. The first step needs no API key or network
beyond cloning; the second needs an Anthropic API key.

## Try it offline

The command above runs a turn against a scripted model, saves the context
as JSON, and loads it for the next run. The repository's default branch follows
development; run `git checkout v0.1.0` first to use the examples of the
release on crates.io. [Examples](/examples/) lists the others; most run
offline too.

## Add Causa to a project

Causa **0.1.0** is on crates.io. The default features include the turn
runner and the Anthropic and OpenAI gateways:

```bash
cargo new causa-hello
cd causa-hello
cargo add causa@0.1.0
cargo add tokio@1 --features macros,rt
```

To leave out the network gateways, or to add the MCP adapters, choose other
features; [Crates and features](/reference/crates/) lists every selection.

## Run one turn

Replace `src/main.rs` with:

<Snippet file="src/bin/getting_started.rs" anchor="program" />

The program builds a gateway for the Anthropic Messages API, a tool executor
with no tools, and a runner that uses both. It starts a `Context` with one
user message and runs one turn with an output limit of 1,024 tokens: the
Anthropic API requires one, and Causa sends no default, so a request without
it fails before it is sent. The runner calls the model, and because the
model asks for no tools, the turn completes after one round; the program
prints the reply.

Set `ANTHROPIC_API_KEY` to your key and `ANTHROPIC_MODEL` to a model ID your
account can use, then:

```bash
cargo run
```

## It's working if

The program prints one sentence from the model and exits.

## If it fails

- `Error: NotPresent` means one of the two environment variables is not
  set.
- `Error: "turn did not complete: …"` carries the cause, such as a rejected
  key or an unknown model ID.
