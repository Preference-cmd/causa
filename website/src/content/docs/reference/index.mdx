title: How to read this reference
description: What the API reference covers, and how it divides the work with docs.rs.
---

The guides show how to do something with Causa. This reference states what
each part of the public API is: what it guarantees, its defaults and options,
how it fails, and whether a change to it would break your code. It is
organized by crate, in the order the [layering](/concepts/layering/) builds
them.

Signatures are not repeated here. Each page links its items to
[docs.rs](https://docs.rs/causa), which is generated from the same release
and has every method and field.

- [Crates and features](/reference/crates/) — the six crates and how to
  select them.
- [Versioning and stability](/reference/versioning/) — what 0.1 promises and
  how to upgrade.
