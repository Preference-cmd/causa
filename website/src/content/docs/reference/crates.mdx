---
title: Crates and features
description: The six Causa crates and how to select them.
---

Depend on `causa`; it re-exports the other five crates, and its features
choose which ones you get. All six share one version and are dual-licensed
`MIT OR Apache-2.0`. Depending on the layer crates directly also works, but
is rarely needed.

## Roles

| Crate | Role | In `causa` as |
| --- | --- | --- |
| [`causa`](https://docs.rs/causa) | One dependency for the whole family, selected by features | — |
| [`causa-kernel`](https://docs.rs/causa-kernel) | The `Context` and the traits other parts implement; no I/O | `causa::kernel`, always |
| [`causa-runtime`](https://docs.rs/causa-runtime) | The turn runner, the tool executor and the retry wrapper | `causa::runtime` |
| [`causa-protocol`](https://docs.rs/causa-protocol) | Request and response translation for the three protocols, streams included; no HTTP | `causa::protocol` |
| [`causa-provider`](https://docs.rs/causa-provider) | The HTTP gateways for the three protocols, built on `reqwest` | `causa::providers` |
| [`causa-extension`](https://docs.rs/causa-extension) | Tool sources; the `mcp` feature adds the MCP client | `causa::extension` |

## Features

| Feature | Adds | Default |
| --- | --- | --- |
| `runtime` | `causa::runtime` | yes |
| `providers` | `causa::providers`, and `protocol` with it | yes |
| `protocol` | `causa::protocol` alone, for translation without HTTP | with `providers` |
| `extension-mcp` | `causa::extension` with the MCP client | no |
| `full` | `runtime`, `providers` and `extension-mcp` | no |

The kernel is always included. A gateway renders through the protocol
crate, so `providers` turns `protocol` on. The MCP client is off by default
because its `rmcp` dependency is large, and an application without MCP
should not have to build it.

Common selections in `Cargo.toml`:

| You need | Dependency |
| --- | --- |
| The runner and the gateways | `causa = "0.1"` |
| The above and MCP servers | `causa = { version = "0.1", features = ["extension-mcp"] }`, or `features = ["full"]` |
| Only the context, to store or inspect conversations | `causa = { version = "0.1", default-features = false }` |
| The runner with your own gateway, no HTTP | `causa = { version = "0.1", default-features = false, features = ["runtime"] }` |

The options of each gateway and protocol are listed in
[Protocol options](/reference/provider/protocol-options/). The API of every
crate is on [docs.rs/causa](https://docs.rs/causa), built with all features.
