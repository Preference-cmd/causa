---
title: Stream decoding
description: Decode a provider's SSE stream with your own HTTP client, without the built-in gateways.
---

The built-in gateways decode streams with `StreamDecoder`, from
`causa::protocol::translation::streaming`. It does no I/O, so an application
that sends requests with its own HTTP client can use it to turn the response
bytes into the same `StreamDelta` values a gateway yields.

## How to drive it

1. Create one decoder per response with `StreamDecoder::new(protocol, limits)`,
   naming the `Protocol` and the [stream limits](/reference/provider/stream-limits/).
2. For each chunk of bytes, call `decode(&mut chunk)` until it returns
   `None`. Each call consumes bytes from the front of the slice and returns
   at most one delta; it can return deltas even when no bytes are left, so
   keep calling until `None` before you read the next chunk.
3. The last delta is `Done`, with the complete `ModelOutput`. After it,
   stop: any bytes that follow are ignored.
4. If the body ends without `Done`, call `finish()`. It reports a cut-off
   stream as an error and never invents the missing end.

An error stops the decoder for good: every later call returns an error too.

For only the SSE framing, the events with their names and data and no
provider-specific assembly, use `SseParser` from
`causa::protocol::translation::sse_parser` in the same way.
