## Experimental 0.0.x

The published **0.0.1** is the first experimental snapshot. The current
checkout contains unreleased breaking changes: editable `Context`, a
material-returning runner, explicit preparation and bound tool processing.
Session management, history policies and subagent orchestration belong to
applications built on Causa. This migration does not announce a new release.

During `0.0.x`, patch releases may break Rust API and serialized-format
compatibility. Breaking changes and migration notes appear at the top of
the release notes. Cargo does not automatically upgrade `"0.0.1"` to
`0.0.2`. Starting with `0.1.0`, breaking wire-serde changes bump the **minor**
version.
