## Experimental 0.0.x

The first experimental release, **0.0.1**, packages
the existing implementation; the **0.1 gate remains functional completeness:
multimodal I/O and subagents.**

During `0.0.x`, patch releases may break Rust API and serialized-format
compatibility. Breaking changes and migration notes appear at the top of
the release notes. Cargo does not automatically upgrade `"0.0.1"` to
`0.0.2`. Starting with `0.1.0`, breaking wire-serde changes bump the **minor**
version. Checkpoint schema versions are validated independently; incompatible
saved material is rejected.
