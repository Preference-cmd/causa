**Causa is a minimal context kernel for Rust agents** — facts in the kernel, behavior in yours.
The kernel carries facts and contracts and nothing else: no I/O, no transport,
no policy. Anything the host didn't opt into doesn't happen.

## Get started

Add the experimental 0.0.1 facade to your Rust project (Rust 1.96+):

```bash
# Default entry: kernel + runtime + providers.
cargo add causa@0.0.1
```

[Build your first application →](/getting-started/)

To try an offline example now, clone the repository and run from its root:

```bash
git clone https://github.com/Preference-cmd/causa.git
cd causa
cargo run --example conversation_persistence -p causa-runtime
```

## Why Causa

<CardGrid>
  <Card title="Facts, not magic" icon="document">
    The kernel is a conversation fact machine plus the behavior ports third
    parties implement against (`ModelGateway`, `Tool`, `ArtifactStore`). Pure,
    offline, auditable — the layer CI forbids from touching I/O.
  </Card>
  <Card title="A driver with visible defaults" icon="setting">
    Turn loop, tool dispatch, streaming, pause/resume, unknown-outcome and
    output-retention policy: config objects and documented component defaults.
    Swappable, never hidden, never a trait seam for a single policy.
  </Card>
  <Card title="Adapters, not opinions" icon="puzzle">
    Providers translate wire protocols; extensions translate tool sources.
    They never decide. Stores, counters, and exporters live in hosts and
    examples — never in the publish set.
  </Card>
</CardGrid>

## How it's layered

<LayerDiagram />

The rule is simple: nothing depends upward, and the kernel depends on
no sibling crate. [Read the concepts →](/concepts/)

## What's inside

| crate | role |
| ----- | ---- |
| `causa` | facade — kernel always on, defaults add runtime + providers |
| `causa-kernel` | facts + contracts, no I/O |
| `causa-runtime` | optional, reference components: turns, dispatch, streaming, pause/resume, sessions |
| `causa-protocol` | pure Anthropic / OpenAI Chat / Responses translation |
| `causa-provider` | reqwest `ModelGateway` adapters |
| `causa-extension` | `mcp` feature: MCP client tool sources |

Need everything? `cargo add causa@0.0.1 --features full`. Auditing offline?
`--no-default-features` is kernel-only. [Full crate guide →](/crates/)

## Learn by running

Run these commands from the repository root after cloning as shown above.

- **Persist a conversation** across restarts — `cargo run --example conversation_persistence -p causa-runtime`
- **Stream a turn** delta by delta — `cargo run --example streaming_print -p causa-runtime`
- **Pause for approval, then resume** with the verdict — `cargo run --example approval_pause_resume -p causa-runtime`

[All examples →](/examples/)
