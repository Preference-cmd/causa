> The API is pre-0.1 and moves fast — the in-tree examples are the source of
> truth for current shapes, not prose. `cargo test --workspace` also
> compiles the current examples, checking their API usage. Live provider and
> MCP server behavior still requires the corresponding integration environment.

All commands below run from the repository root:

```bash
git clone https://github.com/Preference-cmd/causa.git
cd causa
```

The default checkout follows development; run `git checkout v0.0.2` to use
this release's examples. See [Getting started](/getting-started/)
for an application that uses the `causa` facade directly.

## Needs a key or a server

| example | shows | run |
| ------- | ----- | --- |
| `quickstart` (`-p causa-provider`) | one turn + a local tool + a real provider round-trip | `ANTHROPIC_API_KEY=… cargo run --example quickstart -p causa-provider` |
| `mcp_tools` (`-p causa-extension`) | stdio + Streamable HTTP MCP servers into the executor | needs an MCP server (see the example header) |

## Runs offline

| example | shows | run |
| ------- | ----- | --- |
| `conversation_persistence` | save/import `Context` JSON and explicitly run again | `cargo run --example conversation_persistence -p causa-runtime` |
| `streaming_print` | streaming deltas through an optional borrowed `RunEvent` observer | `cargo run --example streaming_print -p causa-runtime` |
| `approval_processor` | approval awaited inside a batch processor | `cargo run --example approval_processor -p causa-runtime` |
| `tool_processors` | ordered tool processors for deduplication and policy | `cargo run --example tool_processors -p causa-runtime` |
| `media_feedback` | host media/artifact storage and example-local output budgeting; only `MediaRef` rides the facts | `cargo run --example media_feedback -p causa-runtime` |

Browse them on GitHub:
[causa-runtime/examples](https://github.com/Preference-cmd/causa/tree/main/crates/causa-runtime/examples),
[provider](https://github.com/Preference-cmd/causa/tree/main/crates/causa-provider/examples),
